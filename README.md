# JASHN Faculty Postcards

A client-side static dashboard for creating 4 x 6 inch faculty postcards and downloading them as PDFs.

## Run locally

Install dependencies once, then start Vite:

```bash
npm install
npm run dev
```

The export button uses the CDN versions of html2canvas and jsPDF, so an internet connection is required when generating PDFs.

## Deploy to Vercel

Import this folder as a static project, or run `vercel` from this directory. No environment variables or server are required.

All photos stay in the browser; nothing is uploaded or stored by the site.
